## Story S1: Filter by task name
**Story**: I want to be able to filter added tasks by their names and find specific tasks
**When [situation/context]**: I want to see all my COMP2870 worksheets, I would filter by COMP2870 to see all of them
**I want [motivation/capability]**: A filter field that allows a user to input a string of their choice and this updates the task list accordingly
**So [outcome/benefit]**: Users can more easily find tasks that they have added according to the task name
**Because [underlying need]**: It helps users more easily find what they are looking for and allows them to quickly navigate through their tasks 

---

## Story S2: Confirmation message
**Story**: I want there to be a status message at the top of the page
**When [situation/context]**: when a user adds, deletes and edits a task
**I want [motivation/capability]**: A status message would give users greater feedback that their actions are actually working
**So [outcome/benefit]**: Users get a visual indicator that their actions are working, so they know what they do is actually working 
**Because [underlying need]**: It gives users greater confidence when they are performing actions, and they know that the page is actually responding to them 

---

## Story S3: Keyboard-only access
**Story**: I want the page to be fully accessible by only using the keyboard
**When [situation/context]**: if a user was to be without a trackpad or mouse
**I want [motivation/capability]**: the page to be fully accessible to these users by allowing them to tab through and access all elements on the page 
**So [outcome/benefit]**: if a user was to be without a mouse they are still able to fully use the website 
**Because [underlying need]**: not all users may have a mouse so it gives greater inclusivity to these users

---

## Story S4: Edit functionality 
**Story**: I want users to be able to edit already added tasks 
**When [situation/context]**: If a user has made a mistake in the name or the name has changed
**I want [motivation/capability]**: users to be able to edit the name of a task in the task list and save it, retaining their changes  
**So [outcome/benefit]**: Users don't have to delete and re-add tasks to the task list if they have made a mistake
**Because [underlying need]**: This can be tedious and time-consuming and it gives users greater control of their tasks.

---

## Story S5: Add and delete tasks
**Story**: I want users to be able to add and delete tasks
**When [situation/context]**: If a user has a new task or has finished a task
**I want [motivation/capability]**: users to be able to add new tasks that they have while being able to delete any from the list that they have finished
**So [outcome/benefit]**: users can interact with the task list, rather than just being able to only add or only delete tasks they can do both
**Because [underlying need]**: The websites core functionality is based on users being able to add and delete tasks and without this it would have little functionality
